# Editable Mockup

There are now two ways to edit this mockup.

## Fastest way

1. Open `http://localhost:3000`
2. Click any blue-underlined text and type
3. Use the bottom-right `Edit Mode` panel to change the main colors

Those edits auto-save in your browser.

## Permanent files

When you want the approved version saved in the repo, edit these files:

- `editable-home.html`
- `editable-dashboard.html`
- `editable-practice.html`
- `editable-mockup.css`

What lives where:

- copy, section order, and page layout: the HTML files
- colors, spacing, typography, borders, and radii: `editable-mockup.css`

## Exporting your browser edits

The `Edit Mode` panel can:

- copy your theme CSS
- download a JSON file of all browser edits
- reset the current page
- reset all browser edits

Browser edits do not write back into the repo files automatically. They are for fast mockup iteration.

## Preview

If the mockup is being served locally, open:

- `http://localhost:3000`

The folder root redirects to `editable-home.html`.

## Keep the original export

The original Claude export still exists in this folder:

- `Guitarmalade SAUCE App v2.html`
- `Guitarmalade SAUCE App.html`
- supporting `.jsx` files

Use the editable files for design changes and keep the original export for reference.
